> 适用于：新能源车评价、电动汽车评测、车型对比、买车决策、购车参考

## 这是什么？

一套面向 **新能源车 / 纯电动 / 插电混动（EV / PHEV / DMi / 增程 / 纯电 SUV）** 的**系统工程评价与购买决策框架**。

它不接受"参数搬运工"式评价（堆配置、比参数、看谁纸面数据强），而是把一辆车拆成 **底层技术 → 硬件能力 → 工程实现 → 实际表现 → 市场验证 → 长期可靠性 → 当前价格** 的完整证据链，最终回答三个完全不同的问题：

> **车好不好？ ≠ 现在值不值得买？ ≠ 适不适合这个用户？**

- 9 大评价维度（能源效率、三电补能、底盘驾驶、安全车身、智能驾驶、智能座舱、设计体验、整车工程、长期可靠性）
- 证据双标体系（来源可信度 + 车型版本匹配度，防"权威但版本不对"）
- 13~18 项真实世界购买因素（终端优惠、政策有效期、售后、TCO、保值率）

适合：想买新能源车但不想被参数表忽悠的人、汽车行业从业者、内容创作者、AI Agent 技能开发者。

## 核心特性（V3.0）

| 特性 | 说明 |
|---|---|
| **9 维产品力体系** | 每个维度独立打分，权重 15/20/15/15/10/7.5/7.5/5/5%，禁止机械平均 |
| **证据双标法** | 每个数据标注 `[来源可信度][车型匹配度]`，如 C-NCAP 官方：[S][A1] |
| **来源可信度** | S 官方/C-NCAP/工信部 ｜ A 权威媒体实测 ｜ B 汽车之家/论坛 ｜ C 单博主 ｜ D 传闻（禁作关键结论） |
| **车型匹配度** | A1 同车型同版本 ｜ A2 同车型不同版 ｜ B 同平台 ｜ C 旧年款 ｜ D 间接推测 |
| **F/I/J 三级标记** | 事实 Fact / 推论 Inference / 判断 Judgment，严禁混用 |
| **评分置信度** | 分数必带置信度（高/中/低）+ 合理区间；反精度原则：宁可"7~8 分"不假装"7.4 分" |
| **反证机制** | 每个关键结论后必须自我质疑："结论可能错在哪里？" |
| **底线机制** | 安全 / 严重可靠性 / 重大质量缺陷 = 一票否决或硬性警告 |
| **配置四级验证** | 硬件 → 能力 → 实际表现 → 用户价值（800V≠补能优秀，激光雷达≠智驾优秀） |
| **三重独立指标** | 产品力 / 当前价格竞争力 / 场景匹配度，三个分数不合并 |
| **模块 10 购买决策层** | 官方价 / 真实落地价 / 国家地方政策（含有效期）/ 售后体系 / 保值率 |
| **TCO 总拥有成本** | 3/5/8/10 年：购车+保险+电费+保养+维修-残值，数据不足给估算区间+假设 |
| **场景权重定制** | 城市通勤 / 高速长途 / 家庭用车 / 驾驶爱好者 / 长期持有，动态调整维度权重 |
| **生命周期评价** | 新车→3→5→8→10 年观察，产品力保持率（无数据禁止伪造） |
| **15 条分析原则** | 参数不是能力；硬件不是体验；降价提升购买价值而非技术水平…… |

## 为什么需要它？

- **参数不等于能力**：800V 不等于补能优秀；激光雷达+700TOPS 不等于智驾优秀；双叉臂+五连杆不等于底盘优秀。
- **版本混淆是重灾区**：Y U7 长续航版实测 ≠ YU7 标准版成绩；2025 款数据 ≠ 2026 款表现。
- **价格是动态的**：指导价 ≠ 实际落地价；产品力 85 分降价 5 万，产品力仍是 85 分，但购买价值飙升。
- **真实电耗 > 宣传续航**：CLTC 与真实差距极大，用户长期数据权重必须高于官方参数。

## 快速使用

### 作为 Hermes Agent Skill 安装

```bash
# 将 SKILL.md 放入 Hermes 技能目录
mkdir -p ~/.hermes/skills/automotive/ev-comprehensive-review
cp SKILL.md ~/.hermes/skills/automotive/ev-comprehensive-review/
```

之后对 Agent 说：
- "分析一下 XX 新能源车值不值得买"
- "XX 和 YY 对比哪个好"
- "帮我看下 XX 这款车的技术水平"

### 手动按体系分析

按 SKILL.md 中的 10 步流程执行即可：确认车型（品牌→车型→年款→版本→动力→电池）→ 参数表 → 9 维评分 → 短板 → 隐藏优势 → 反证 → 价格/优惠/售后 → TCO → 竞品对比 → 最终结论。

## 报告输出结构

```
1. 一句话结论
2. 车型身份确认（品牌/车型/年款/版本/电池/驱动形式）
3. 核心参数表（关键参数标注 [来源可信度][车型匹配度]）
4. 九维产品力评分（每维：分数+置信度+事实+分析+证据+短板）
5. 反证检查：结论最可能错在哪里？
6. 当前价格、优惠与售后（官方价/真实价/政策/售后/保值率）
7. TCO（3/5/8/10 年）
8. 用户场景匹配
9. 最大优势 / 10. 最大短板 / 11. 最大未知风险
12. 最终结论 + 购买建议五档（强烈推荐/值得考虑/视需求购买/谨慎考虑/不推荐）
```
