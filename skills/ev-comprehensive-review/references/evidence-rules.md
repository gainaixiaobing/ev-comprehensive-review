# 证据体系细则

> 本文档定义证据收集、审查和使用的详细规则。

## 来源可靠性分级

| 等级 | 来源 | 典型用途 |
|---|---|---|
| **S** | 官方技术资料、配置表、工信部、C-NCAP、C-IASI、权威测试机构、官方召回 | 车型参数、安全测试、官方价格、质保 |
| **A** | 权威汽车媒体实测、多家独立媒体交叉验证、大量真实车主长期数据 | 实际能耗、续航、充电速度、制动、NVH |
| **B** | 汽车之家、懂车帝、车质网、车主论坛、大规模用户反馈 | 终端价格、车主口碑、高频故障、保值率 |
| **C** | 单个车主、单个博主、短视频、社交媒体帖子 | 发现问题，而不是证明问题 |
| **D** | 无来源传闻、自媒体猜测、AI 生成文章 | 仅作待验证线索，不得作为评分依据 |

---

## 车型匹配度

| 等级 | 含义 |
|---|---|
| **A1** | 完全对应：中国 + 当前版本 + 当前动力系统 |
| **A2** | 同车型同平台，版本高度接近，存在轻微差异 |
| **B** | 同车型但不同市场 |
| **C** | 同平台不同车型 |
| **D** | 仅技术路线相似 |

**双标判断**：如 C-NCAP 官方测试 = [S][A1]；Euro NCAP 欧版用于中国版 = [S][B]（来源可靠但市场不匹配）。

跨市场数据不得伪装成中国版直接测试结果。

---

## Fact / Inference / Judgment

所有关键证据必须归类：

| 标签 | 含义 | 示例 |
|---|---|---|
| **Fact** | 可验证的客观事实 | 官方公布续航 675km / 某媒体实测能耗 15kWh/100km |
| **Inference** | 基于多个事实的合理推断 | 整备质量低 + Cd 低 → 能耗效率较高 |
| **Judgment** | 最终评价 | 能源效率 8.5 分 |

**禁止：**

- 把宣传数据写成实测数据
- 把其他版本成绩写成目标版本成绩
- 把媒体观点写成客观事实
- 把推断伪装成来源结论

---

## 官方宣传 vs 真实能力

| 类型 | 含义 | 限制 |
|---|---|---|
| **宣传事实** | 官方申报/宣传（如 CLTC 675km） | 只能证明官方申报，不能直接证明实际能力 |
| **能力事实** | 多次独立实测平均 | 评分优先依据 |

能力事实 > 宣传事实。

适用于：续航、快充速度、智驾能力、加速、能耗、NVH、底盘能力。

## 消费者调查规则

### 何时使用

设计、内饰、座椅、车机体验、满意度等存在天然主观性的维度，允许使用消费者调查作为证据。

### 引用格式

```
调查来源：XX
调查主体：XX
调查时间：XXXX年X月
样本数量：XXXX 人
调查对象：车主 / 潜在消费者 / 随机抽样
调查方法：问卷 / 访谈 / 平台数据
核心结论：XX% 受访者认为……
局限性：XX
```

### 禁止

- 自行声称「消费者普遍认为……」除非有样本支持
- 把二手媒体引用调查当作原始调查
- 不同调查结论冲突时强行平均

### 调查质量审查

必须考虑：

- 样本量是否足够
- 样本是否具有代表性
- 调查对象是车主还是潜在消费者
- 主动参与还是随机抽样（粉丝偏差风险）
- 调查机构是否可靠
- 问题设计是否诱导
- 是否为二手转述

## 反证机制

研究过程中必须主动寻找反面证据：

- 官方宣传与实际测试不一致
- 不同媒体测试结果冲突
- 用户投诉和高频故障
- 长期可靠性问题
- 配置缩水/版本差异
- 价格变化趋势
- 产品短板
- 极端场景表现

**核心原则：研究的任务不是证明这辆车很好，而是主动寻找它为什么可能不值得买。**

反证有效性门槛：

- 单个车主帖子 → 只能作为异常案例
- 多个独立车主相同故障 → 可作为趋势线索
- 大规模数据 + 专业测试 + 召回 → 可作为系统性反证

---

## 同级来源冲突处理

两个同级来源冲突时，依次判断：

1. 是否不同日期/版本/市场/生产批次？
2. 是否一个是历史页面？
3. 价格/优惠优先级：当前下单页 > 当前配置页 > 活动页 > 新闻稿 > 媒体 > 平台

无法判断时：不得强行裁决，标记「信息冲突」。

---

## 数据不足的处理

明确区分：

- **表现差**：有充分证据表明表现不佳
- **证据不足**：没有足够数据判断好坏

两者不能混淆。证据不足时写「暂无可靠数据 / 证据不足」，不得自行补数字或降低评分。
